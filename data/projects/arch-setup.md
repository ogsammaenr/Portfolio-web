# Arch Linux Setup Scripts
Bu proje, **Arch Linux** kurulumundan sonra **Hyprland** ortamını saniyeler içinde kurmak için geliştirildi.

## Özellikler
- Waybar ve Rofi konfigürasyonu.
- Otomatik paket yönetimi (yay/paru).
- Minimalist pencere kuralları.

## Kod Örneği
Aşağıdaki bash scripti ile kurulum başlar:
```bash
chmod +x install.sh
./install.sh
```
